03 / THE SMALL PRINT

One checklist, an open trail.

01

Read public evidence

The contract accepts only a standard GitHub issue URL and reads a bounded excerpt from that issue.

02

Assess independently

The leader and validators each check whether the problem, steps, context, and evidence are present.

03

Record agreement

Matching checklist fields are stored with a readiness score. The issue body is not written to contract state.
